  over shared globals (stdout capture, `colorEnabled`, command registry,

  the e2e `go/parser` meta-test to `cmd`. M, MED risk.
- **DOCS-02** CLAUDE.md's engine map is wrong: `RestackAll`/`PruneMerged`
  return `[]string` (not `*OpResult`) and `Sync`/`Abort`/`Continue`/`Repair`

  S; high value for agent onboarding.
- **TESTS-01** The shell shim (cmd/shell.go:84-114) is only ever
  string-grepped, never executed by bash/zsh/fish in any test. Add an
  execution test with a stub `st` writing `ST_CD_FILE` (skip when a shell
  binary is absent). S. NOTE: the audit's "fish breaks on paths with spaces"
  sub-claim was WRONG (fish splits command substitution on newlines, not
  spaces) — the gap is the missing execution coverage, not a known bug.
- **TESTS-02** Only 4 golden fixtures (help, log tree/json, status json);
  the text output of submit/sync/status/worktree/undo/restack and the error

  maintainer taste call.
- **DX-04** No git tags exist, so `make build` stamps a bare commit hash,
  `go install ./cmd/st` ships the stale default `0.1.0` (cmd/root.go:21),
  and the goreleaser path has never run. Cutting a `v0.2.0` tag (CHANGELOG's
  Unreleased section is ready) is a maintainer release decision, not an

- **CORRECTNESS-CMD-03** `runAbort` builds `stackEnv(nil, …)` whose

### Direction findings (maintainer options, not ranked against fixes)

- **Remote-parent sync** (new, MED confidence): `Sync` fetches/FFs only the
  trunk (engine.go:625) while `submit -u` gives every branch an upstream it
  then ignores — the clearest surface asymmetry for teams sharing a stack
  (teammate force-pushes your parent; no `st` way to pull + cascade). Scope
  as a design spike: semantics for a force-pushed parent, dry-run, opt-in.
  L overall.
- **`st serve` / MCP** (deepened from 2026-06-12): the command/flag registry
  already emits a machine-readable tool manifest (`help --json`,
  root.go:161/186; AGENT.md:124-129), so an MCP server's tool schema could be
  *generated* rather than hand-written; a long-lived server also amortizes
  the per-op subprocess+lock cycle. M–L spike; demand still inferred.
- **`absorb` spike** (refined): the risky piece — hunk→ancestor-commit
  attribution — is a pure function over blame output, exactly the shape the
  fake-git + model-test harness already fuzzes in milliseconds; the spike is
  materially smaller than the "large subsystem" framing suggests. Build-out
  stays deferred per CLAUDE.md. L spike.
- **Parent-amendment detection** (carried from 2026-06-12): `validate` flags
  drift but not a parent amended/force-pushed outside `st`. M, MED.
- **`st redo`** (recorded, likely not worth it): a full backward journal
  exists with no forward counterpart, but redo semantics are ambiguous once
  tips move after an undo — a naive redo silently reapplies against a changed
  graph. Investigate-only; "not worth doing" is the expected verdict.
