## Findings considered and rejected

- **018 / copy-time symlink exfiltration:** cmd/worktree_copy.go recreates symlinks with Readlink/Symlink; cmd/worktree_test.go:725 explicitly requires outside-target link preservation, and broken links are deliberately supported. Source-parent escape is separately checked. A stricter link policy would be a product change, not the demonstrated vulnerability claimed by the plan.
- **001 / empty old-OID means absent in NUL framing:** incorrect. In `update-ref -z --stdin`, empty means no verification; zero means require absence. Zero new-OID deletes and is not a valid restore target. See the authoritative references in AUDIT.md.
- **004 and 006 / grep the key comment for encryption:** incorrect. Minisign uses the same default secret-key comment for both key forms; its signing action does not use `-W` as a no-prompt guard.
- **005 / ambient version or installer-test override alone establishes an attack:** unsupported. Preserve legitimate explicit overrides; validate archive structure independently. The proposed release-JSON explanation also ignores quote escaping.
- **002 / detached-owner lookup alone proves Git deletes a paused branch:** unproven. Git has its own worktree protections; retain the lookup/conformance investigation with narrower claims.
- **Generic runtime shell injection, proxy handling, Windows runtime CI absence, and removal of dirty-tree refusal:** inspected argv boundaries and documented tradeoffs do not establish these defects. Makefile version interpolation is a separate confirmed build boundary (F11).
- **Performance promises without measurement:** no claimed speedup for CI parallelization, broad caching, or checkpoint batching. Plan 020's post-rebase OID reuse is unsupported by the current error-only port methods.
- **DX-11** (`install.sh` sudo-mv chmod false failure): `mv` under sudo preserves ownership in both same-fs and cross-fs cases — `chmod` can't fail that way. The adjacent `get_latest_version` `head -1` nit is folded into plan 005.
- **DX-03** (js/wasm `vet-cross` gap): `GOOS=js GOARCH=wasm go build ./...` compiles clean today, and wasm can't spawn `git` at all — the lock-owner degradation is unreachable. Marginal.
- **PERF-09** (`cyclePath`/`Children` O(N²) walks): microseconds at realistic stack sizes — cosmetic, not worth a plan.
- **DOCS-13** (0.0.1 "Windows CI" changelog entry): historically accurate — remote CI existed at that release and was removed later (the `.github/workflows/` deletion is recorded in history). Not drift.
- **PERF-12** (journal/state fsync measurement): kept as investigate-only inside plan 020's Step 4 — measure before optimizing.
- **Direction suggestions** (not planned — maintainer call, listed for the roadmap): push-staleness surface in `log`/`status`/`submit --dry-run` (upstream-tracking refs already recorded by `PushBranches`; the read path is absent — HIGH confidence, M effort); `st show`/`st commits` against `parentSHA` (S effort, primitives exist); `st each` (per-worktree command runner — needs a design decision on worktree-less branches); `create --insert` (mid-stack insert — primitives exist, topology care needed); shareable stack topology export/import over git transport.
- **Rejected approach**: `--autostash` for restack/sync — the dirty-tree refusal is a consistent, deliberate safety posture across `ErrDirty`/exit-4; a feature decision, not a defect.
