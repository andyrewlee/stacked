## Findings considered and rejected

- All eight CORRECTNESS findings from the audit subagent, after first-hand vetting:
  - "Duplicate save in `st continue`" — the tail-save is the same pattern `mutate()` applies to every command; harmless and consistent.
  - "Delete leaves children pointing at a deleted parent on conflict" — false: `RemoveBranch` re-parents children *before* the save; the saved state is exactly what `st continue` needs (the documented Onto-style design).
  - "PendingReparent not cleared on non-conflict rebase failure" — misread: it is only ever set inside the in-progress branch, which returns immediately.
  - "lock_other.go reclaim TOCTOU" — the implementation is content-conditional removal behind a reclaim guard; the second O_EXCL attempt resolves races correctly. The *real* gap is CI never compiling it → plan 003.
  - Lock/load TOCTOU, concurrent-delete-during-Onto, inferParent fallback, nil-state defensive checks — speculative, lock-excluded, or explicitly by-design.
- **DEBT-01** (parseArgs vs parseFlagSet inconsistency) — by design: commands with positionals use the shuffling `parseArgs`; flag-only commands use `parseFlagSet` + `rejectArgs`.
- **DEBT-02** (split the 965-line engine.go) — not yet; cohesive, low churn. Revisit if engine churn rises.
- **DEBT-04** (delete the Shell wrapper), **DEBT-07** (flag defaults), **DEBT-08** (delete plan9 lock owner), **DEBT-09** (emit boilerplate), **DEBT-10** (errors.New vs fmt.Errorf) — style-level; the audit's own verdict was "not worth doing".
- **DX-02** (.editorconfig) — gofmt + the fmt-check gate already enforce formatting; marginal.
- **DX-05** (move build artifacts to bin/) — cosmetic; everything is correctly gitignored.
- **SECURITY** dir-permission note (.git/stacked 0755 + files 0600) — by design for a single-user local tool; file modes are what matter and are correct.
- **DIRECTION-04** (`submit --draft` via branch-name prefixing) — renaming branches to signal draft status breaks branch identity and stack metadata; wrong mechanism for a login-free tool.
